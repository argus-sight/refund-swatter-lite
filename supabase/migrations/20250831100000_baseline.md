# 20250831100000_baseline.sql 指令说明

> 本文件按迁移脚本中现有的章节顺序，对每一条 SQL 指令给出用途说明，方便逐条查阅。注：以下说明中的对象名称均指向 `public` schema，除非特别标注。

## Extensions & Cron Schema ACL
- `CREATE EXTENSION IF NOT EXISTS pg_cron WITH SCHEMA extensions;`：确保安装 `pg_cron`，用于调度定时任务。
- `CREATE EXTENSION IF NOT EXISTS pg_net WITH SCHEMA extensions;`：安装 `pg_net`，支持数据库内部的 HTTP 请求。
- `CREATE EXTENSION IF NOT EXISTS supabase_vault WITH SCHEMA extensions;`：启用 Supabase Vault，用来安全管理密钥/秘密。

## Session Settings
- `SET statement_timeout = 0;`：取消语句超时，避免长时间迁移被中断。
- `SET lock_timeout = 0;`：取消锁超时，保证迁移获取锁时不会因等待超时失败。
- `SET idle_in_transaction_session_timeout = 0;`：取消事务空闲超时，防止长事务被终止。
- `SET client_encoding = 'UTF8';`：确保客户端编码为 UTF-8。
- `SET standard_conforming_strings = on;`：使用标准 SQL 字符串格式。
- `SELECT pg_catalog.set_config('search_path', '', false);`：把 `search_path` 设为空，强制所有对象引用使用带 schema 前缀的全名（增强安全性）。
- `SET check_function_bodies = false;`：允许创建函数时不立即验证函数体（避免依赖尚未创建的对象导致失败）。
- `SET xmloption = content;`：设置 XML 解析选项，保持默认内容模式。
- `SET client_min_messages = warning;`：只显示警告及以上级别消息，减少噪音。
- `SET row_security = off;`：禁用 RLS 的当前会话应用，避免迁移受 RLS 影响（迁移后再重新启用）。

## Schema Setup
- `CREATE SCHEMA IF NOT EXISTS "public";`：确保存在 `public` schema。
- `ALTER SCHEMA "public" OWNER TO "pg_database_owner";`：将 schema 所有者设置为数据库所有者角色，方便集中管理。
- `COMMENT ON SCHEMA "public" IS 'standard public schema';`：添加 schema 注释，说明这是标准公共 schema。

## Functions（安全敏感辅助函数）
### cleanup_old_data
- `CREATE OR REPLACE FUNCTION public.cleanup_old_data(p_days_to_keep integer DEFAULT 180) RETURNS void ...`：清理过期的通知、API 日志和作业数据；参数控制保留天数（默认 180 天）。
- `ALTER FUNCTION public.cleanup_old_data(p_days_to_keep integer) OWNER TO postgres;`：把函数所有者改为 `postgres`，确保执行权限与安全上下文可控。

### decode_jwt_payload
- `CREATE OR REPLACE FUNCTION public.decode_jwt_payload(jwt_token text) RETURNS jsonb ...`：拆解并解码 JWT，返回 payload JSON，异常时返回 `NULL`。
- `ALTER FUNCTION public.decode_jwt_payload(jwt_token text) OWNER TO postgres;`：指定 `postgres` 为函数 owner。

### get_apple_private_key
- `CREATE OR REPLACE FUNCTION public.get_apple_private_key() RETURNS text SECURITY DEFINER ...`：以 SECURITY DEFINER 身份从 Vault 读取 Apple 私钥；使用 `search_path=''` 防止路径劫持。
- `ALTER FUNCTION public.get_apple_private_key() OWNER TO postgres;`：确保该高权限函数以 `postgres` 身份定义。

### get_consumption_metrics_summary
- `CREATE OR REPLACE FUNCTION public.get_consumption_metrics_summary(p_environment text DEFAULT NULL) RETURNS TABLE(...) ...`：汇总最近 30 天的消费请求指标，可按环境过滤，返回请求数、成功率等。
- `ALTER FUNCTION public.get_consumption_metrics_summary(p_environment text) OWNER TO postgres;`：设定 owner。
- `COMMENT ON FUNCTION public.get_consumption_metrics_summary(p_environment text) IS '...';`：为函数写注释，说明用途。

### get_lifetime_dollars_enum（cents 版本）

- `ALTER FUNCTION public.get_lifetime_dollars_enum(amount_in_cents integer) OWNER TO postgres;`：设定 owner。
- `COMMENT ON FUNCTION public.get_lifetime_dollars_enum(amount_in_cents integer) IS '...';`：记录用途。

### get_lifetime_dollars_enum（numeric 版本）

### get_playtime_enum

### handle_updated_at

### process_pending_notifications_direct
- `CREATE OR REPLACE FUNCTION public.process_pending_notifications_direct() RETURNS void SECURITY DEFINER ...`：作为 Edge Function 的后备方案，批量把待处理通知标记为 processing 并写入日志。

- `CREATE OR REPLACE FUNCTION public.store_apple_private_key(p_private_key text) RETURNS uuid SECURITY DEFINER ...`：把新的 Apple 私钥存入 Vault，并更新配置表中的引用。

## Default Privileges（默认权限）
- `-- ALTER DEFAULT PRIVILEGES ... TO authenticated;`：注释掉，说明刻意不为 authenticated 设置默认 sequence 权限。
- `ALTER DEFAULT PRIVILEGES FOR ROLE postgres IN SCHEMA public GRANT ALL ON SEQUENCES TO service_role;`
- `ALTER DEFAULT PRIVILEGES FOR ROLE postgres IN SCHEMA public GRANT ALL ON TABLES TO service_role;`
- `-- ALTER DEFAULT PRIVILEGES ... TABLES TO authenticated;`：注释掉，保持最小权限。

## Reset
- `RESET ALL;`：把本次会话修改过的参数恢复默认，以免影响后续操作。

## Function Privilege Hardening（函数权限收紧）
- `REVOKE EXECUTE ON ALL FUNCTIONS IN SCHEMA public FROM PUBLIC;`：撤销所有公共执行权限。
- `REVOKE EXECUTE ON ALL FUNCTIONS IN SCHEMA public FROM anon, authenticated;`：撤销匿名/认证角色的执行权限。
- `ALTER DEFAULT PRIVILEGES FOR ROLE postgres IN SCHEMA public REVOKE EXECUTE ON FUNCTIONS FROM PUBLIC;`
- `ALTER DEFAULT PRIVILEGES FOR ROLE postgres IN SCHEMA public REVOKE EXECUTE ON FUNCTIONS FROM anon, authenticated;`
- `ALTER DEFAULT PRIVILEGES FOR ROLE pg_database_owner IN SCHEMA public REVOKE EXECUTE ON FUNCTIONS FROM PUBLIC;`
- `ALTER DEFAULT PRIVILEGES FOR ROLE pg_database_owner IN SCHEMA public REVOKE EXECUTE ON FUNCTIONS FROM anon, authenticated;`
- `GRANT EXECUTE ON FUNCTION public.get_consumption_metrics_summary(text) TO authenticated;`：白名单恢复给客户端可用的函数。
